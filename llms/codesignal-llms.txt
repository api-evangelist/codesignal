# CodeSignal

> CodeSignal is a technical interview and skills-assessment platform. Its developer surface exposes a GraphQL API, a versioned Learn REST API (OpenAPI 3.1), a webhook event API, and an official remote MCP server for AI agents to work with assessments, candidate test sessions, and live interviews.

## APIs
- [GraphQL API](https://app.codesignal.com/graphql): Primary API for companies, tests, test sessions, interviews, and interview templates. HTML schema docs at developer.codesignal.com.
- [Learn Public API](https://codesignal.com/learn/api/v1/openapi): OpenAPI 3.1 REST API for organization members, skill sets, and learning progress. OAuth 2.0 client-credentials.
- [Webhook API](https://developer.codesignal.com/): 14 event types across assessment, candidate, auditor, and live-interview workflows; HMAC-SHA256 signed deliveries.
- [MCP Server](https://codesignal.com/api/mcp): Official remote MCP server (HTTP transport, Bearer API key).
